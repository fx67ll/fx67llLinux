# linux-conf

个人`linux`系统配置文件备份记录

## 目录说明

| 目录 | 说明 |
| :---- | :---- |
| `redis-conf` | `Redis`配置备份（多版本/实例） |
| `system-conf` | 系统配置备份（`profile`） |
| `tomcat-conf` | `Tomcat`配置备份（`server.xml`） |
| `tomcat-sh` | `Tomcat`启动脚本备份（`catalina.sh`、`setclasspath.sh`） |

> `unix`配置文件在`Windows`下修改会出现`^M`，此处仅作备份请勿下载修改；如需改动请在`linux`下做`^M`去除
