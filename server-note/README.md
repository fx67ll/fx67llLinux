# server-note

服务器运维相关笔记，按主题目录分类整理

## 目录说明

| 目录 / 文件 | 说明 |
| :---- | :---- |
| `application-note` | 应用与站点迁移记录 |
| `halo-note` | `halo`博客平台部署与迁移记录 |
| `operation-note` | 服务器运维手册与检查清单 |
| `other-note` | 其他工具笔记（`PM2`、`UFW`） |
| `safty-note` | 服务器安全防护记录（安全事件、`Fail2ban`） |
| `server-restart.md` | 服务重启运维记录 |

> 日常运维优先参考`operation-note`下的运维手册与检查清单
