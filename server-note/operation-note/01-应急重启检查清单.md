# 应急重启检查清单

---

**最后更新时间：2026年8月6日**

---

> **适用场景**：服务器宕机 / 重启后 / 服务异常挂掉，需要按顺序恢复
> **预计耗时**：5~10 分钟
> **核心顺序**：防火墙 → Nginx → Tomcat → Node → Halo

---

## 一、核心服务重启（按顺序）

### ✅ 1. 防火墙

```bash
service iptables start
```

**验证**：
```bash
service iptables status
```

> 💡 防火墙没开的话，外部所有端口都访问不了，但本地可以。先确认防火墙状态再排查其他。

---

### ✅ 2. Nginx

```bash
nginx
```

**验证**：浏览器访问首页，或 `curl localhost`

> 💡 启动失败大概率是配置语法错，用 `nginx -t` 检查。

---

### ✅ 3. Tomcat（跑 Jenkins）

```bash
cd /usr/soft/install/apache-tomcat-9.0.7/bin
./startup.sh
```

**验证**：访问 `IP:8080` 看 Tomcat 主页

> 💡 启动前确保 8080 端口没被占用：`netstat -tlnp | grep 8080`

---

### ✅ 4. Node 服务

```bash
cd /usr/node/JDSMS
pm2 start app.js --name="fx67llNode"
```

**验证**：
```bash
pm2 list
```

> 💡 避坑：
> - 确保 `.env` 环境变量文件存在
> - 迁移过服务器的话，检查 MongoDB 连接地址是否正确
> - 更新环境变量用 `pm2 restart <应用名> --update-env`

---

### ✅ 5. Halo 博客

```bash
sudo systemctl start halo
```

**验证**：
```bash
sudo systemctl status halo
```

**常用命令**：
```bash
sudo systemctl stop halo       # 停止
sudo systemctl restart halo    # 重启
sudo systemctl enable halo     # 开机自启
```

**配置文件**：`~/.halo/application.yaml`

> 💡 避坑：
> - H2 数据库控制台平时关闭（`enabled: false`）
> - `web-allow-others` 保持 `false`，避免外部访问数据库
> - 缓存模式选 `memory` 即可

## 二、非常态服务（已关闭，按需开启）

> 一般不需要开启，特殊情况才用

| 服务 | 端口 | 开启命令 | 关闭命令 | 状态查询 |
|------|------|---------|---------|---------|
| MySQL 5.7 | 3306 | `service mysql start` | `service mysql stop` | `service mysql status` |
| MySQL 8.0 | 3307 | `service mysql80 start` | `service mysql80 stop` | `service mysql80 status` |
| Redis 6.2 | 6379 | `cd /usr/soft/install/mongodb-linux-x86_64-rhel70-4.4.4/bin && redis-server redis.conf` | `redis-cli -h 127.0.0.1 -p 6379 -a 你的redis密码 shutdown` | `redis-cli ping` |
| MongoDB | 27017 | `cd /usr/soft/install/mongodb-linux-x86_64-rhel70-4.4.4/bin && ./mongod -f mongodb.conf` | ⚠️ 不会运维，炸了重装 | — |

> ⚠️ MongoDB 没事别乱动，炸了只能重装

## 三、防火墙端口管理

### 开放新端口

```bash
cd /etc/sysconfig
vim iptables
# 添加：-A INPUT -p tcp -m state --state NEW -m tcp --dport 端口号 -j ACCEPT
service iptables restart
```

> 💡 每开一个应用端口，一定要同步开防火墙端口；宝塔面板还有一层安全组，两边都要检查

## 四、重要目录速查

| 路径 | 用途 |
|------|------|
| `/usr/soft` | 软件安装包和解压包 |
| `/usr/share/nginx` | Nginx 静态文件 |
| `/etc/nginx` | Nginx 配置 |
| `/etc/ssl` | SSL 证书 |
| `/etc/sysconfig/iptables` | 防火墙配置 |
| `/usr/node` | Node 应用 |
| `~/.halo` | Halo 工作目录 |

---

## 五、重启后验证清单

- [ ] `service iptables status` → 防火墙运行中
- [ ] 浏览器访问首页 → Nginx 正常
- [ ] `pm2 list` → Node 服务在线
- [ ] `IP:8080` → Tomcat / Jenkins 正常
- [ ] `IP:8090` → Halo 博客正常
- [ ] `fail2ban-client status` → 防爆破正常
